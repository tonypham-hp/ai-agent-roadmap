# Tài liệu hướng dẫn

Tổng cộng **5** tài nguyên trong danh mục này.

- [Google's Agent Whitepaper](https://kaggle.com/whitepaper-agents) — Tài liệu chuyên sâu của Google về AI Agent
- [Google's Agent Companion](https://kaggle.com/whitepaper-agent-companion) — Tài liệu bổ trợ giúp hiểu rõ hơn về AI Agent
- [Building Effective Agents by Anthropic](https://anthropic.com/engineering/building-effective-agents) — Hướng dẫn xây dựng AI Agent hiệu quả từ Anthropic
- [Claude Code Agentic Coding Practices](https://code.claude.com/docs/en/best-practices) — Các phương pháp lập trình theo hướng AI Agent với Claude Code
- [OpenAI's Practical Guide to Building Agents](https://cdn.openai.com/business-guides-and-resources/a-practical-guide-to-building-agents.pdf) — Hướng dẫn thực tiễn của OpenAI về xây dựng AI Agent
