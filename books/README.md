# Sách

Tổng cộng **7** tài nguyên trong danh mục này.

- [Understanding Deep Learning](https://udlbook.github.io/udlbook/) — Hiểu sâu về Deep Learning
- [Building an LLM from Scratch](https://manning.com/books/build-a-large-language-model-from-scratch) — Xây dựng mô hình ngôn ngữ lớn từ đầu
- [The LLM Engineering Handbook](https://oreilly.com/library/view/llm-engineers-handbook/9781836200079/) — Cẩm nang kỹ thuật xây dựng ứng dụng LLM
- [AI Agents: The Definitive Guide](https://oreilly.com/library/view/ai-agents-the/0642572247775/) — Hướng dẫn toàn diện về AI Agent
- [Building Applications with AI Agents](https://oreilly.com/library/view/building-applications-with/9781098176495/) — Xây dựng ứng dụng với AI Agent
- [AI Agents with MCP](https://oreilly.com/library/view/ai-agents-with/9798341639546/) — Xây dựng AI Agent với MCP
- [AI Engineering](https://oreilly.com/library/view/ai-engineering/9781098166298/) — Kỹ thuật xây dựng và triển khai ứng dụng AI
